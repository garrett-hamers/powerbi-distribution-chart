# Security Policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately through
[GitHub Security Advisories](https://github.com/garrett-hamers/powerbi-distribution-chart/security/advisories/new).
Do not include secrets or sensitive customer data in a public issue.

This visual is designed to use no network requests, external assets, or
privileged capabilities. Security reports should include the affected version,
reproduction steps, and impact where available.
